## 🧭 The Vision

This is Task 1 of my web development internship at **WeIntern Pvt Ltd**. 

The goal wasn't just to write code, but to build a lightweight, fast, and visually stunning digital identity that represents who I am as a developer. No heavy JS frameworks, no templates. Just pure **HTML5, CSS3, and Vanilla JavaScript** working in harmony. It's built to load instantly, adapt to any screen size, and look premium.

## ⚡ Page-by-Page Breakdown

### 🏠 Home (`index.html`)
- **Hero & Intro:** A clean, bold typography headline that establishes my focus on Web Development & AI.
- **CTA Routing:** Smooth interactive buttons to immediately view projects or download my CV.
- **Stat Strip:** High-impact minimal stats card showing my educational focus and hackathon achievement.

### 🧑‍💻 About (`about.html`)
- **Story Timeline:** A styled journey track showing my education and experience milestones.
- **Stack Manifest (Bento Grid):** A customized, 4-column desktop grid organizing frontend stacks, programming languages, backend & data, and my current learning path.
- **Value Cards:** Interactive card deck highlighting key personal philosophies (Precision, Innovation, Empathy).

### 🛠️ Projects (`projects.html`)
- **Showcase Cards:** Features real projects (like HerCycle AI and Pollutree Monitor) with custom tech stack pills.
- **Asymmetric Grid:** Utilizes custom desktop spans to create a modern, editorial aesthetic layout rather than a standard, boring grid.

### ✉️ Contact (`contact.html`)
- **Clean Form:** Minimalistic inputs with focus rings and outline transitions.
- **Validation Engine:** Custom Vanilla JavaScript logic that validates user input on-the-fly and shows helpful state feedback without reloading the page.

## 🛠️ Tech Stack & Spacers

| Technology | Role |
|------------|------|
| **HTML5 (Semantic)** | Ensuring proper SEO, layout hierarchy, and accessibility (`<nav>`, `<main>`, `<section>`). |
| **CSS3 (Custom Properties)** | Global tokens for colors, spacings, borders, and smooth transitions. |
| **Tailwind CSS (CDN)** | Rapid utility-first layouts, responsive breakpoint modifiers, and custom color configuration. |
| **Vanilla JavaScript ES6+** | Handling drawer navigation, scroll intersection animations, and form validations. |
| **Google Fonts** | Elegant editorial typography combination (*Noto Serif* & *Plus Jakarta Sans*). |

## 🚀 Running Locally

This project runs entirely on static files. No dependencies, no npm overhead.

```bash
# Clone the repository
git clone https://github.com/khushi897920-lang/weintern-web-dev-week1.git

# Enter the portfolio folder
cd weintern-web-dev-week1/portfolio-website

# Open in browser
open index.html
# Alternatively, drag index.html directly into any web browser!
```
